Connecte tes comptes pour télécharger automatiquement tes posts enregistrés Reddit et tes likes X. Les identifiants restent sur ta machine (accounts.json, jamais versionné).

Reddit — posts enregistrés

Comment obtenir les identifiants ?
  1. Connecté à Reddit, ouvre reddit.com/prefs/apps
  2. « create another app… » → coche script
  3. redirect uri : http://localhost:8080 (obligatoire mais inutilisé)
  4. L'ID client est sous le nom de l'app, le secret à côté de « secret »
Avec la double authentification (2FA), le mot de passe devient motdepasse:code2FA.
Laisser vide pour conserver le secret déjà enregistré.

X (Twitter) — likes

Comment ça marche ?
Tes likes ne sont visibles que par ton propre compte : le téléchargeur réutilise la session X de ton navigateur — connecte-toi simplement à x.com dans le navigateur choisi.
  1. Firefox recommandé — Chrome/Edge récents chiffrent leurs cookies et bloquent souvent la lecture.
  2. Alternative : exporter un cookies.txt avec une extension (ex. « Get cookies.txt LOCALLY ») et indiquer son chemin ci-dessous.
